Step 1

Install Tampermonkey

  1. Open Google Chrome.
  2. Click Install Tampermonkey.
  3. On the Chrome Web Store page, click Add to Chrome.
  4. When Chrome asks for confirmation, click Add extension.
  5. Wait for Chrome to confirm that Tampermonkey has been added.

Step 2

Install the userscript

  1. Click Install Userscript.
  2. On Greasy Fork, click Install this script.
  3. Tampermonkey will open a new install screen. Click Install.
  4. Open or refresh your MFL page.
  5. The Pylon Cam MFL Tools userscript is now ready for bulk message board posting.

Troubleshooting

If the userscript does not appear

  1. Open Chrome Extensions by typing chrome://extensions in the address bar.
  2. In the top-right corner, make sure Developer mode is turned on.
  3. Find Tampermonkey, click Details, and make sure the extension is turned on.
  4. In Tampermonkey’s extension settings, make sure Allow user scripts is turned on if that option appears.
  5. Make sure Tampermonkey has permission to run on the MFL website. If Chrome shows a site-access option, choose On all sites or allow it for the MFL site.
  6. Click the Tampermonkey icon, open the Dashboard, and confirm that PylonCam MFL Tools is installed and enabled.
  7. Refresh the MFL page after installing or changing any extension settings.
  8. If it still does not work, temporarily disable browser security, ad-blocking, or web-threat extensions that may block userscripts from running.
  9. If Chrome says the URL is restricted, try opening the actual MFL league page directly instead of running the script from a browser settings page, extension page, new tab page, or Chrome Web Store page.

Most issues are caused by Chrome extension permissions, Tampermonkey being disabled, the userscript being turned off, or another browser extension blocking script behavior.
